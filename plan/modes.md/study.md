This file describes the study mode of Algo Buddy.

When the user selects study mode, the website will ask what they are struggling with. The user's input is then passed to the OpenAI API by prompting the LLM to
give useful information that helps them understand more about the algorithm. This can be about the code, the time complexity, or about the algorithm's real world use cases.

Within the same mode, there is an option to quiz the user on the helpful/supplemental information given to the user by the LLM in this session.
